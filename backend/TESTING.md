## 覆盖的行为

| 场景 | 断言 |
|---|---|
| 固定口径 | 同批次重复提交相同指标/分箱/总预算返回原口径；改动任一项返回 409 |
| 预算不足 | 剩余预算不足以覆盖本次 ε 时返回 409「余额不足」，事务回滚，不留下发布行 |
| 最后一份预算并发争用 | 两个线程同时申请（1.0 与 0.75，总预算 1.0），恰好一个成功、一个被拒；剩余额度等于总预算减去获批请求，发布行数为 1 |
| 相同冻结输入并发重试 | 三个线程用不同名称提交同一输入/分箱/ε，全部成功且指向同一发布，只扣一次费，发布行数为 1 |
| 改名复用 | 同输入改名重试返回 `reused=true` 与原名称，预算不变 |
| 输入变化 | 新增观测后再次提交生成新发布并再次扣费 |
| 噪声确定性 | 同一已存种子两次生成得到完全相同的计数与 ECDF；发布后再重试不会重抽 |
| 同一份非负计数 | 箱计数均为非负整数；`noisy_total=sum(counts)`；ECDF 末值为 1，每一步等于该箱累计/总数；分位数由公开计数重算一致 |
| 待生成到可用 | pending 时 `result=null`、`downloadable=false`、导出返回 409；worker 完成后才开放查看与下载 |
| 生成失败 | 扰动计算抛错时状态 failed、结果保持隐藏、错误留存、预算不退回，且不提供重试（需修复数据后重新提交） |
| 扣费后写档失败 | 模拟写档 `OSError`：状态回到 pending、`result` 仍隐藏、错误为「留档失败」、预算已扣；重试后复用完全相同的结果并完成留档 |
| 观察员入口 | `/overview`、`/studies`、`/studies/{id}/observations`、`/runs`、`/runs/{id}`、`/runs/{id}/export`、`/audits` 均不返回受保护批次的原值、精确行数或历史精确研究（审计只保留 protection.* 事件）；分析师与负责人仍可读取 |
| 权限 | 只有负责人可冻结口径；分析师可申请发布；观察员申请被拒 403 |
